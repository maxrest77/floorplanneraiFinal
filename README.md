Floor Plan AI

Floor Plan AI is a web application that leverages AI to analyze, visualize, and manage building floor plans. It allows users to interact with floor plan data, perform edits, and securely authenticate to access personalized features.

Features

AI-powered floor plan visualization

Interactive editing tools: move, rotate, scale, erase elements

User authentication: Firebase Email/Password & Google Sign-In

Responsive design: works on desktop and mobile

Deployment ready: hosted on Firebase Hosting

Tech Stack

Frontend: node
.js

Authentication & Hosting: Firebase Auth & Firebase Hosting

State Management & UI: React hooks, custom components

Installation
git clone https://github.com/yourusername/floor-plan-ai.git
cd floor-plan-ai
npm install
npm start

Deployment

Build the project and deploy to Firebase Hosting:


npm run build
firebase deploy
